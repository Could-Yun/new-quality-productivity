# 可视化导论 · AI × 新质生产力

> 《可视化导论》课程作业 —— 用交互可视化呈现人工智能作为新质生产力的作用与意义。

一篇**可交互的数据新闻长卷**：从宏观产业曲线出发，经由要素流动、三十一省产业版图、行业渗透场景，落到四个行业里真实发生的效率跃迁。全站支持**中英双语切换**。

## 两个核心交互设计

**① 滚动驱动的图表形变（第 02 节）**
同一份数据随滚动在柱状图 → 双轴柱线图 → 面积图 → 环形图 → 雷达图之间依次变换，用 ECharts `universalTransition` 实现形态过渡——用五种可视化方法回答五个递进的问题。

**② 多视图联动 Brushing & Linking（第 04 节）**
地图、排序条形图、平行坐标、气泡散点**共享同一份选择状态**，任一视图中点击或刷选，其余视图同步响应，并支持年份时间轴播放。

> 💡 在平行坐标的「智能算力」轴上刷选高值区间，会筛出内蒙古、宁夏、贵州、甘肃——这些省份产业规模不大但算力很高，正是**"东数西算"**国家工程的空间体现。该结论单看任一视图均无法发现。

## 数据说明

- 标注 **[实测]** 的数字来自公开权威报道（工信部、国家知识产权局、新华网、求是网、农业农村部等，2024–2026），完整来源列于页脚。
- 省级细分维度（智能算力、人才指数、企业数）为依据公开资料整理的**量级估算**，仅用于教学性可视化的相对比较，不作为精确统计引用。

## 技术栈

- 原生 HTML / CSS / JavaScript，**无构建步骤**，无框架依赖
- [Apache ECharts](https://echarts.apache.org/) 5（本地内置于 `assets/vendor/`）
- 中国地图 GeoJSON（本地内置）

## 本地运行

因为页面需要 `fetch` 加载地图 GeoJSON，直接双击 `index.html` 会被浏览器的同源策略拦截，需起一个本地服务器：

```bash
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000/
```

## 无障碍与健壮性

- **渐进增强**：内容默认可见，确认 `IntersectionObserver` 可用后才接管入场动画；并设有兜底定时器，避免观察器不回调时整页空白。
- 尊重 `prefers-reduced-motion`，首屏粒子动画滚出视口后自动停止以节省 CPU。
- 响应式已在 1440 / 1024 / 768 / 375 四档宽度 × 中英双语下验证，横向溢出均为 0。
